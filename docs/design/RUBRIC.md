# Taskora Visual Design Evaluation Rubric (17-Point Rubric)

This rubric establishes the formal acceptance criteria for reviewing designs generated by Google Stitch and reviewing implemented pages in Taskora. Every criterion is scored `0` (fails) or `1` (passes).

**Acceptance Threshold:** Minimum score of **15 / 17** with **zero critical [حرج] items failing**.

---

### Criteria

1. **[حرج] Visual Hierarchy:** Clear page title, followed by a single dominant primary action, followed by cleanly stratified content blocks without competing focal points.
2. **[حرج] Singular Primary Action:** Exactly one prominent primary call-to-action per screen state (no two competing saturated buttons).
3. **Consistent Spacing Grid:** Strict adherence to 4px/8px multiples with no cramped zones and generous whitespace separating major analytical and content sections.
4. **Typographic Discipline:** At most two font families (`Fraunces` for display/headlines/KPIs, `Instrument Sans` for body/controls; `Amiri` and `IBM Plex Sans Arabic` for Arabic). Constrained scale (≤ 6 font size steps) and consistent font weights (400, 500, 600).
5. **Restrained Color Palette:** Structured neutral surfaces (`--bg`, `--surface`, `--surface-raised`), single primary champagne gold accent (`#D4B26E` / bronze `#7A5818`), and dedicated semantic status colors (`todo`, `in_progress`, `done`, `overdue`); no arbitrary rainbow decorative fills.
6. **[حرج] Contrast & Semantic State Representation:** WCAG 2.1 AA compliance (≥ 4.5:1 for standard text, ≥ 3.0:1 for graphical/UI controls). Status and priority indicators must pair semantic text with distinct SVG iconography—never relying solely on color.
7. **[حرج] Application Shell & Sidebar:** Unambiguous navigation containing Taskora brand logo, primary navigation links (Dashboard), Projects section showing active task count per project, primary "+ New project" trigger, and bottom user profile card. Seamlessly converts to an accessible focus-trapped drawer on viewports < 1024px.
8. **Appropriate Density & Scaled Roundness:** Calibrated for executive productivity—neither sparse nor cluttered. Radii scale hierarchically by role: small for inputs/controls (6px), medium for panels/tables (10px), dialogs (14px), full pill for status badges, and 0px for sidebar.
9. **Engineered Empty, Loading, and Error States:** Explicitly designed empty states with helpful guidance ("what happened" + "what to do next"), skeleton structures matching page anatomy (no full-page spinners), and localized error cards with retry actions.
10. **Zero Phantom Features:** Completely pristine Phantom Features Audit. No notification bells, no global search bars, no billing/upgrade buttons, no growth percentages (+12%), no historical time-series charts, no detail inspector pane, and no chat widgets.
11. **RTL Mirroring & Logical Layouts:** Fully reversible for Arabic without layout breakage: zero dependence on hardcoded physical left/right CSS properties, correct logical margins/paddings (`margin-inline-start`, `inset-inline-start`), and directional arrows properly mirrored (`rtl:rotate-180`).
12. **[حرج] Distinct Brand Identity (Not Generic SaaS):** No generic SaaS look (no light gray canvas with identical 12px rounded white boxes, no default Tailwind indigo/blue, no Inter font). When viewed without a logo, the interface is immediately identifiable as Taskora's private obsidian ledger. Champagne accent strictly restricted to 3 placements.
13. **Visual Rhythm & Surface Depth:** Explicit surface stratification (`--bg` → `--surface` → `--surface-raised`) instead of boxing everything into borders. Focused size contrast between headlines and body. Charts use restrained monochrome/champagne palettes.
14. **[حرج] Luxury & Craftsmanship Feel:** Editorial luxury feel inspired by high-end horology and private banking ledgers. Generous white space, hairline rules (1px), subtle inner highlights in dark mode (`inset 0 1px 0 rgba(239, 233, 221, 0.04)`), and zero neon/fluffy drop shadows.
15. **Polished State Consistency:** Systematic hover, active, focus, disabled, and invalid states for all controls. Uniform icon stroke width (1.5px/2px). Arabic typography renders natively without fallback font degradation.
16. **[حرج] Ledger Principle (Hairlines, Not Card Soup):** Sections and lists are rendered as a continuous, refined ledger separated by hairline rules (`#2C2824` / `#DDDAD3`), rather than cutting up the page into identical rectangular cards. At most two raised surfaces on the entire page.
17. **[حرج] Tabular Display KPI Numerals:** Key performance indicators and metrics are set in high-contrast `Fraunces` display serif with tabular lining figures (`font-variant-numeric: lining-nums tabular-nums`) creating high visual drama against calm secondary metadata labels.
