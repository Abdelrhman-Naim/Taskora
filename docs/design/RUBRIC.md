# Taskora Visual Design Evaluation Rubric (11-Point Rubric)

This rubric establishes the formal acceptance criteria for reviewing designs generated by Google Stitch and reviewing implemented pages. Every criterion is scored `0` (fails) or `1` (passes).
**Acceptance Threshold:** Minimum score of **9 / 11** with **zero critical [حرج] items failing**.

---

### Criteria

1. **[حرج] Visual Hierarchy:** Clear page title, followed by a single dominant primary action, followed by cleanly stratified content blocks without competing focal points.
2. **[حرج] Singular Primary Action:** Exactly one prominent primary call-to-action per screen state (no two competing saturated buttons).
3. **Consistent Spacing Grid:** Strict adherence to 4px/8px multiples with no cramped zones and generous whitespace separating major analytical and content sections.
4. **Typographic Discipline:** At most two font families (e.g. Inter / Alexandria / Cairo), constrained scale (≤ 6 font size steps), and consistent font weights (400, 500, 600).
5. **Restrained Color Palette:** Structured neutral surfaces (canvas, surface, surface-elevated, text, muted), single primary brand accent, and dedicated semantic status colors (`todo`, `in_progress`, `done`, `overdue`); no arbitrary rainbow decorative fills.
6. **[حرج] Contrast & Semantic State Representation:** WCAG 2.1 AA compliance (≥ 4.5:1 for standard text, ≥ 3.0:1 for graphical/UI controls). Status and priority indicators must pair semantic text with distinct SVG iconography—never relying solely on color.
7. **[حرج] Application Shell & Sidebar:** Unambiguous navigation containing Taskora brand logo, primary navigation links (Dashboard), Projects section showing active task count per project, primary "+ New project" trigger, and bottom user profile card. Seamlessly converts to an accessible focus-trapped drawer on viewports < 1024px.
8. **Appropriate Density & Scaled Roundness:** Calibrated for executive productivity—neither sparse nor cluttered. Radii scale hierarchically by role: small for inputs/checkboxes (4px/6px), medium for buttons/cards (8px/12px), full pill for status badges.
9. **Engineered Empty, Loading, and Error States:** Explicitly designed empty states with helpful guidance ("what happened" + "what to do next"), skeleton structures matching page anatomy (no full-page spinners), and localized error cards with retry actions.
10. **Zero Phantom Features:** Completely pristine Phantom Features Audit. No notification bells, no global search bars, no billing/upgrade buttons, no growth percentages (+12%), no historical time-series charts, and no chat widgets.
11. **RTL Mirroring & Logical Layouts:** Fully reversible for Arabic without layout breakage: zero dependence on hardcoded physical left/right CSS properties, correct logical margins/paddings, and directional arrows properly mirrored (`rtl:rotate-180`).
