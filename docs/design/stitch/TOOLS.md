## Detailed Tool Specifications

### 1. `create_project`
- **Description:** Creates a new Stitch project. A project acts as a container for UI designs and frontend code.
- **Parameters:**
  - `title` (string, optional): Display title of the project (e.g. `"Taskora"`).
- **Returns:** Project object with resource name (format: `projects/{projectId}`), title, and timestamps.

### 2. `get_project`
- **Description:** Retrieves the details of a specific Stitch project, including screen instances.
- **Parameters:**
  - `name` (string, required): Resource name format: `projects/{projectId}` (e.g., `projects/15314095118624877827`).
- **Returns:** Project details, screenInstances list with `id` and `sourceScreen`.

### 3. `list_projects`
- **Description:** Lists projects available in the Stitch workspace.
- **Parameters:**
  - `filter` (string, optional): Filter expression for projects.
- **Returns:** `{ projects: Project[] }`

### 4. `delete_project`
- **Description:** Deletes a project.
- **Parameters:**
  - `name` (string, required): `projects/{projectId}`
- **Safety Restriction:** **STRICTLY PROHIBITED** from calling `delete_project` on existing user projects without explicit instruction.

### 5. `generate_screen_from_text`
- **Description:** Generates a new UI screen based on a textual description and optional design parameters.
- **Parameters:**
  - `projectId` (string, required): Numeric project ID string (without `projects/` prefix).
  - `prompt` (string, required): Detailed prompt describing layout, purpose, sections, and constraints.
  - `deviceType` (string, optional): One of:
    - `"DESKTOP"`
    - `"MOBILE"`
    - `"TABLET"`
    - `"AGNOSTIC"`
  - `modelId` (string, optional): One of:
    - `"GEMINI_3_8_FLASH"`
    - `"GEMINI_3_5_FLASH_LITE"`
  - `designSystem` (DesignSystem object, optional): Direct inline design system overrides.
- **Returns:** Created screen metadata, including resource name `projects/{projectId}/screens/{screenId}`.

### 6. `get_screen`
- **Description:** Retrieves the details of a specific screen within a project, including raw HTML/CSS output.
- **Parameters:**
  - `name` (string, required): Full screen resource name: `projects/{projectId}/screens/{screenId}`.
- **Returns:** Screen object with:
  - `name`: Screen identifier.
  - `htmlContent` / `code`: HTML and CSS representation.
  - `thumbnailUrl` / `imageUrl`: Rendered preview image URL (if generated by Stitch).
- **Local Fallback:** If image download is unavailable, `reference.html` is opened with Playwright (Chromium) to capture full-fidelity screenshots at 1280px (Desktop) and 390px (Mobile).

### 7. `list_screens`
- **Description:** Lists all screens associated with a specific project.
- **Parameters:**
  - `projectId` (string, required): Numeric project ID string without `projects/`.
- **Returns:** Array of screen summaries.

### 8. `edit_screens`
- **Description:** Edits existing screens based on a prompt (e.g. removing phantom features or tweaking density).
- **Parameters:**
  - `projectId` (string, required)
  - `selectedScreenIds` (array of string, required): Screen IDs to modify.
  - `prompt` (string, required): Specific instructions for edits.
  - `deviceType` (string, optional): `"DESKTOP" | "MOBILE" | "TABLET" | "AGNOSTIC"`
  - `modelId` (string, optional): `"GEMINI_3_8_FLASH" | "GEMINI_3_5_FLASH_LITE"`
- **Returns:** Updated screen details.

### 9. `generate_variants`
- **Description:** Generates visual and structural variants of an existing screen.
- **Parameters:**
  - `projectId` (string, required)
  - `selectedScreenIds` (array of string, required)
  - `prompt` (string, required): Exploration guidance.
  - `variantOptions` (object, optional):
    - `variantCount` (number, 1-5): Number of variants to generate.
    - `creativeRange` (string): `"REFINE" | "EXPLORE" | "REIMAGINE"`.
    - `aspects` (array of string): Subset of `["LAYOUT", "COLOR_SCHEME", "IMAGES", "TEXT_FONT", "TEXT_CONTENT"]`.
- **Returns:** Generated variant screen objects.

### 10. `create_design_system`
- **Description:** Creates a new foundational design system for a project or globally.
- **Parameters:**
  - `projectId` (string, optional): Numeric project ID.
  - `designSystem` (object, required):
    - `displayName` (string, required): Human-readable name.
    - `theme` (object, required):
      - `colorMode` (string, required): `"LIGHT" | "DARK"`
      - `headlineFont` (string, required): Font enum (e.g. `"INTER"`, `"MANROPE"`, `"PLUS_JAKARTA_SANS"`, `"GEIST"`, `"RUBIK"`)
      - `bodyFont` (string, required): Font enum
      - `labelFont` (string, optional): Font enum
      - `customColor` (string, required): Primary brand hex color (e.g. `"#1e3a8a"`).
      - `roundness` (string, required): `"ROUND_FOUR" | "ROUND_EIGHT" | "ROUND_TWELVE" | "ROUND_FULL"`.
      - `colorVariant` (string, optional): `"MONOCHROME" | "NEUTRAL" | "TONAL_SPOT" | "VIBRANT" | "EXPRESSIVE"`.
      - `overridePrimaryColor`, `overrideSecondaryColor`, `overrideTertiaryColor`, `overrideNeutralColor` (hex strings, optional).
      - `designMd` (string, optional): Freeform markdown guidelines.
      - `spacing` (object, optional): Spacing token dictionary.
      - `typography` (object, optional): Token level definitions.
- **Follow-up:** Call `update_design_system` or `apply_design_system` to attach to project/screens.

### 11. `create_design_system_from_design_md`
- **Description:** Creates a design system from an uploaded DESIGN.md file.
- **Parameters:**
  - `projectId` (string, required)
  - `selectedScreenInstance` (object, required): `{ id: string, sourceScreen: string }`
  - `deviceType` (string, optional)
- **Pre-requisite:** Must invoke `upload_design_md` immediately before calling this.

### 12. `upload_design_md`
- **Description:** Uploads a base64-encoded `DESIGN.md` file to a Stitch project.
- **Parameters:**
  - `projectId` (string, required): Target project ID without `projects/`.
  - `designMdBase64` (string, required): Base64-encoded UTF-8 string containing markdown design guidelines.

### 13. `update_design_system`
- **Description:** Updates an existing design system asset.
- **Parameters:**
  - `name` (string, required): Resource name format: `assets/{assetId}`.
  - `projectId` (string, required)
  - `designSystem` (object, required): Updated DesignSystem definition.

### 14. `list_design_systems`
- **Description:** Lists design systems available for a given project or globally.
- **Parameters:**
  - `projectId` (string, optional)
- **Returns:** `{ designSystems: DesignSystem[] }`

### 15. `apply_design_system`
- **Description:** Applies a design system asset across selected screen instances.
- **Parameters:**
  - `projectId` (string, required)
  - `assetId` (string, required): Asset ID of the design system.
  - `selectedScreenInstances` (array of objects, required):
    - `id` (string): Screen instance ID.
    - `sourceScreen` (string): Resource name `projects/{projectId}/screens/{screenId}`.

## Operating Protocol & Best Practices

1. **Isolation from Codebase:**
   Stitch outputs HTML and CSS (often using Tailwind CDN or inline styles) purely as an interactive/visual reference. Code generated by Stitch must **never** be copied into `src/`. All implementation in Taskora is custom React + CSS Modules using `tokens.css`.
2. **Quota Control:**
   Phase 4 budget is strictly capped at **80 generations**. Every generation (`generate_screen_from_text`, `edit_screens`, `generate_variants`) increments `generationsUsed` in `docs/design/stitch/manifest.json`.
3. **Phantom Features Elimination:**
   Generated screens often hallucinate UI components with no backend model in Taskora (e.g. notifications bells, billing, analytics charts over time). These must be stripped via `edit_screens` or pruned during implementation according to `docs/design/phantom-features.md`.
